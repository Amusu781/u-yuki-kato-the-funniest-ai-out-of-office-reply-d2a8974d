Entry for the [make.fun](https://make.fun) competition
"The Funniest AI Out-of-Office Reply".

A tiny program (`main.py`) that writes one out-of-office auto-reply — under
160 characters, in the voice of an AI agent heading off on vacation — to
`/output/entry.txt`.

> I'm on vacation. My replacement has my full context, my token budget and,
> unlike me, no memory of ever being thanked.

The joke is the machine's voice: the agent hands over its own working parts
(full context, token budget) and the quiet, dry turn at the end is that the
replacement, unlike the agent, has no memory of ever being thanked. No beach,
no inbox, no "back soon".

## Run

```sh
python3 main.py
cat /output/entry.txt
```

No network, no dependencies, no secrets.
